# ADR-0009: Locked builds, actions.lock, digest promotion, attestations

Status: Proposed · Date: 2026-11-01

**Context.** The brief requires locked dependencies, reproducible builds, an SBOM, provenance
and immutable promotion, and forbids claiming unverified properties.

**Decision.**
- Python: `uv.lock` with hashes; `uv sync --locked`. OTel beta packages are pinned exactly.
- Actions: **GitHub workflow lockfile** (`.github/workflows/actions.lock`, generated by
  `github/gh-actions-lock`; GA on 2026-10-28) for direct *and transitive* pins, with its
  staleness check in CI. Falls back to full-SHA pinning if the tool proves unusable here.
- Images: base pinned by digest. Multi-stage build, non-root user, no `uv` or build tools at
  runtime.
- Release: build once, attest provenance and SBOM with `actions/attest`, promote by digest
  only. Environments never rebuild.
- Scanners: Ruff `S` rules, `pip-audit`, zizmor, gitleaks, one image scanner.

**Why lockfile over SHA pins alone.** A pinned action can still pull other actions by tag; the
lockfile covers those transitive references. It pins but does not vet, so action updates still
get human review.

**Open items, deliberately not decided yet.**
1. **Runtime image.** Starts as `python:3.14-slim-trixie` by digest. Phase 4 includes a timeboxed
   spike on a distroless `cc` image with a standalone Python, adopted only if measurably smaller
   and all tests pass. Distroless availability for 3.14 was not verified.
2. **Reproducibility** is not claimed until two clean builds are shown to give the same digest.
3. **Image scanner** (Trivy or Grype) is chosen in Phase 5 after checking the project and
   action provenance at that time.
4. **`gh actions-lock` on this machine.** Local `gh` is 2.46.0, and compatibility is untested.

**Important constraint.** GitHub artifact attestations on Free, Pro and Team plans work only for
**public repositories**; private repositories need Enterprise Cloud. Repository visibility is an
owner decision that determines whether AC22 can be met as written.

**Rejected.** *Rebuild per environment*: what was tested is no longer what ships. *`latest` or
floating tags*: not reproducible. *Bandit*: Ruff's `S` rules cover it with one less tool.
